# Cascades beyond R0 on GIRGs

Seed-level prediction of cascade take-off on geometric inhomogeneous random
graphs, with node features and graph neural networks. Follow-up to
[girg-cascades](https://github.com/ParsaTheParser/girg-cascades).

Ongoing research; training and experiment code will be released with the paper.

- features.py: node features
- models.py: MLP and GNN (GINE) models
- girg_core.py: shared code from girg-cascades
